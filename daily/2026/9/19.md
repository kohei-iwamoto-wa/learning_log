## 学んだこと

### Amazon Inspector

AWS上のリソースに存在する**セキュリティ上の脆弱性を自動的に検出・評価するサービス**です。

主に以下のようなセキュリティリスクを評価します。

- EC2のOS・インストール済みパッケージの脆弱性
- ECRのコンテナイメージの脆弱性
- Lambda関数のコード・依存関係の脆弱性
- ネットワーク到達性などのセキュリティ上の問題

Amazon Inspectorは、基本的に**脆弱性を検出・評価するサービス**であり、検出した脆弱性を自動的に修正するサービスではありません。

### 他のセキュリティサービスとの違い

- **Amazon Inspector**：脆弱性を検出・評価
- **Amazon GuardDuty**：不審なアクティビティや脅威を検出
- **Amazon Macie**：S3に保存された機密データを検出
- **AWS Security Hub**：各種セキュリティサービスの検出結果を集約

## AWS Data Exchange datashare

Amazon Redshiftのデータを、**AWS Data Exchangeを通じて外部の利用者に提供・ライセンスするための仕組み**です。

Redshiftのデータをコピー・移動することなく、利用者が自身のRedshiftから共有されたデータを直接クエリできます。

主な特徴は以下です。

- Redshiftのデータをコピーせずに共有できる
- AWS Data Exchangeを通じて第三者にデータを提供できる
- データのサブスクリプション（購読）に対応
- データ提供者が共有するスキーマ・テーブル・ビューなどを指定できる
- 利用者は自分のRedshiftから共有データをクエリできる
- データ提供者が更新したデータを利用できる
- データのライセンスやサブスクリプションなどをAWS Data Exchangeで管理できる

### Redshift Data Sharingとの違い

**Redshift Data Sharing**

→ Redshift間でデータをコピーせず共有する仕組み

**AWS Data Exchange datashare**

→ Redshift Data Sharingを利用して、**外部の利用者にデータを商品・ライセンスとして提供する仕組み**

つまり、

> **Redshift Data Sharing = データを共有する**

> **AWS Data Exchange datashare = データを外部に提供・販売する**

というイメージです。

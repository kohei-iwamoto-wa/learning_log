#### VPC Peerin vs PrivateLink


|         | VPC Peering       | AWS PrivateLink              |
| ------- | ----------------- | ---------------------------- |
| 接続単位    | **VPC ↔ VPC**     | **サービス ↔ VPC**               |
| 通信      | 双方向的なVPC間通信が可能    | 基本的にConsumer → Service       |
| アクセス範囲  | 広い                | **限定的**                      |
| ルートテーブル | 必要                | 通常、VPC PeeringのようなVPC間ルートは不要 |
| CIDR重複  | **不可**            | 重複環境でも使いやすい                  |
| 用途      | VPC同士をネットワークとして接続 | API・サービスを他VPCへ公開             |
| 典型例     | 開発VPC ↔ 本番VPC     | SaaS/API提供VPC → 顧客VPC        |

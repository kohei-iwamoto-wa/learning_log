## AutoScaling

* EC2 Auto Scaling：EC2インスタンスの台数を自動で増減する。
* Application Auto Scaling：ECSタスクやDynamoDBなど、アプリケーション系リソースの容量を自動で増減する。


## OrganizationAccountAccessRole

AWS Organization の管理アカウントに作成される

管理アカウントからメンバアカウントにアクセスするときに使う

```
【管理アカウント】
       │
       │ AssumeRole
       ▼
【メンバーアカウント】
OrganizationAccountAccessRole
       │
       ▼
   EC2 / S3 / Lambda
```

## EFA（Elastic Fabric Adapter）

HPCやAI/MLで、EC2同士を低レイテンシー・高スループットで通信させるためのネットワークデバイス

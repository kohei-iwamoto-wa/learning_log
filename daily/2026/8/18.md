#### Lambda エイリアス

Lambdaのエイリアスは、関数のバージョンへの指示子です。
エイリアスを参照することで、lambdaのバージョンが変更になった場合でも、呼び出し元の修正が不要になる。


エイリアスの紐付けを変更する
```
aws lambda update-alias \
  --function-name my-function \
  --name alias-name \
  --function-version version-number
```

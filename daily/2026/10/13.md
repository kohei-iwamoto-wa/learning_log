### 学んだこと

* HTTP API
  * HTTP APIは機能を絞って低価格にしたAPIであり、APIキーと使用量プランのどちらにも対応していません。
* REST API
  *  REST APIの使用量プランでは、日次、週次、月次のいずれかの期間に対するリクエスト数の上限と、1秒あたりのレートおよびバーストを定義できます。

### 学んだこと

#### API Gateway

* HTTP API
  * HTTP APIは機能を絞って低価格にしたAPIであり、APIキーと使用量プランのどちらにも対応していません。
* REST API
  *  REST APIの使用量プランでは、日次、週次、月次のいずれかの期間に対するリクエスト数の上限と、1秒あたりのレートおよびバーストを定義できます。

#### Saving Plan

* EC2 Instance Savings Plans
  * 特定のリージョン ＋ インスタンスファミリーにコミットする。その分、割引率が高い。
* Compute Savings Plans
  * EC2の構成変更に柔軟。FargateやLambdaにも適用できる。

#### AWS Storage Gateway

S3 File Gateway	ファイル（NFS／SMB）	S3へのファイル保存・バックアップ
FSx File Gateway	ファイル（SMB）	オンプレミスからFSx for Windows File Serverにアクセス
Volume Gateway	ブロック（iSCSI）	オンプレミスのサーバーにブロックストレージを提供

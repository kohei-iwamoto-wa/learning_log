* AWS Firewall Manager 

### 学んだこと

#### AWS Firewall Manager 対応サービス

AWS WAF（Webの攻撃対策・IP制限など）

AWS Shield Advanced（DDoS攻撃対策）

Amazon VPC セキュリティグループ（ポートやIPのアクセス制御）

AWS Network Firewall / Network Director（ネットワーク層のファイアウォール）

Amazon Route 53 Resolver DNS Firewall（不正なドメインへの通信遮断）

#### ユースケース

大量のアカウントを所有する組織で、共通のFirewallの設定を管理アカウントで設定しておくことで、子アカウントに自動的に設定が反映される

* 嬉しいこと
  * 設定漏れがなくなる
  * 新しいアカウントが作成されると自動的に設定が反映される

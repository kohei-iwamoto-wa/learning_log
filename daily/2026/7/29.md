#### AWS Batch

AWS Batch とは、大規模なバッチ処理を効率的に実行するためのフルマネージドサービス。

コンピューティングリソースのプロビジョニングやジョブのスケジューリングを AWS が管理してくれるため、利用者はバッチ処理の実行内容に集中できる。

主に以下のような用途で利用される。

* 機械学習の学習処理
* 遺伝子解析
* 大量データの分析処理
* 科学技術計算

AWS Batch では、以下の要素を組み合わせてバッチ処理を実行する。

* Job Definition
  * 実行するコンテナイメージやCPU・メモリなどの実行条件を定義

* Job Queue
  * ジョブを投入するキュー

* Compute Environment
  * ジョブを実行するコンピューティングリソース
  * EC2やFargateを利用可能

処理量に応じてコンピューティングリソースを自動的にスケールできるため、大規模なバッチ処理環境を容易に構築できる。
